# Security policy

## Reporting a problem

If you find a security issue in this role, for example a setting that weakens a system or a way it could lock users out, please **don't open a public issue**.

Use GitHub's private reporting instead: go to the **Security** tab of this repository and choose **Report a vulnerability**.

I'll acknowledge reports within 7 days and aim to fix confirmed issues within 30 days.

## Scope

This is a personal project, built and tested in a home lab. Test it on a non-production machine before using it anywhere that matters.
